# 0.6.0 阅读与管理改进记录

0.5.1 已完成 tag CI、正式发布和华为平板 App 内更新验证，再开展本轮功能。

## 已实现并在浏览器验证

- 全屏独立图片布局，不再每次翻页移动原生视图。自动/单页/双页，竖屏单页、宽平板横屏双页，手机横屏仍优先单页；旋转保留当前页。
- 当前页与前后相邻页保持解码，空闲逐步准备后续页；派生 PNG 放在独立 IndexedDB，LRU 上限 64 MB。源码和批注数据库不参与缓存淘汰。
- 新页面解码完毕后整体切换。当前桌面 Chrome 中预热后的双页前进/后退约 5–8 ms，计时从手指抬起到页码变更后的动画帧；这不是平板性能结论。重新进入全屏命中持久缓存时，当前页原生渲染调用为 0。
- 音符命中使用原生模型，选中图形使用 MuseScore 原生绘制和声部颜色。播放竖线与自动翻页仍使用原生页面/节拍坐标。
- 播放进度随对应 PCM 块输出到设备的时间通知主线程，合并积压并丢弃过期的运行进度。浏览器中人为阻塞界面 450 ms 后未逐条追赶，采样通知与输出时钟最大差约 17 ms，未增加断流；不代表已测得实体扬声器的声学延迟。
- 外观的曲谱背景开关、透明原生谱纸、统一胶囊按钮和圆角面板。
- 本地乐谱长按管理、持久重命名、按字节校验导出、取消与确认删除、选择性清理批注和派生页面。重命名不改谱内标题、不加入最近阅读。
- 云端详情页查看来源、文件格式/大小/版本及本地状态，在详情内下载，下载后由用户主动打开；返回保留筛选与滚动。真实静态曲库验证不调用 GitHub REST API。
- 既有 PDF 三种排版、全屏缩放/翻页、批注跨翻页及重新打开保留；原生自由看谱、样式设置、移调、撤销验证通过。

对应脚本：`tools/verify-spread-reader.mjs`、`verify-audible-clock.mjs`、`verify-library-management.mjs`、`verify-live-cloud.mjs`、`verify-reader-fixes.mjs`、`verify-pdf-gallery.mjs`。截图和本机报告在被 Git 忽略的 `tests/results/`，不上传用户乐谱。

## 设备验证

正式发布包已在 MuMu Android 15 中验证离线 MSCZ 导入、点击音符后视图不移动、原生音符选择、全屏双页触摸前后翻页和播放竖线。1280×800 CSS 视口，预热后双页前进/后退约 15.5/15.6 ms；5 秒播放区间断流计数未增加。模拟器结果不能代替实体平板。

同一发布包上也已验证原始 MSCZ 的高音谱表隐藏后，保留低音谱表播放持续前进，撤销后恢复谱表并继续播放。设备脚本等待停止完成，并使用与 UI 相同的完整撤销 action URI。

0.6.0 APK 已构建并提交华为平板系统安装。系统要求设备持有人输入锁屏密码，等待直接在设备上完成验证；安装后再核对原有 5 份文件和 1 份批注，记录真实翻页与播放表现。

MuseTab 0.6.7

- 声部发声开关改为更新播放过滤规则，复用整首曲子的已有数据；暂停后静音、重新开启和再次播放不再重建整首音频事件。
- 显示、隐藏谱表与声音设置分开处理，保留当前播放位置和原生撤销、重做、MSCZ 保存。
- 释放已过期的原生播放缓存，限制移动端画布与音频内存分配，减少切换时的额外开销。
- 播放准备、声部更新、模式切换、乐谱打开、符号和 PDF 页面加载增加旋转提示，阻止重复点击。
- 恢复后台返回后的音频上下文；音频线程异常时显示原因，避免界面无反馈地停住。

Android 9+。使用与此前开发包相同的签名，可覆盖安装保留本地数据。安装更新仍需 Android 系统确认。
PDF 识别仍在开发阶段，本版不含 OMR，PDF 暂不能直接播放。

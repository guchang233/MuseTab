# 0.6.3 播放位置与外观修复

## 播放位置

旧的编辑页在打开版面面板和样式设置时调用 `engine.stop()`；MuseScore 的 stop 会把音频时钟归零。现在改为 pause，保持已有时钟位置。版面内显示/隐藏操作在播放期间也先暂停。现有的谱表可见性事件重建逻辑保留；无需更换本版的原生 runtime v3。

使用用户提供 MSCZ 的独立导入副本验证：打开版面后暂停在 2.4 秒附近，隐藏谱表后位置不变，继续播放推进；重新显示、全部隐藏后恢复也从旧位置继续。MuMu Android 15 通过实际显示控件验证：暂停在 2.773 秒，隐藏后仍为 2.773 秒，再播放到 3.883 秒；播放中显示谱表后暂停在 4.075 秒，继续到 4.971 秒。原文件未修改。

## 圆角范围

移除给所有 button 强加 999px 圆角的通用规则。设置遮罩原本也是 button，所以被误画成了椭圆。现在遮罩为 0 圆角，图标按钮、动作按钮、表单、设置行和面板各自定义形状；移除 focus-visible 强加的轮廓圆角，并恢复源卡片/设置行样式。

页面和样式弹窗在手机/平板横竖屏、明暗两种主题下，检查四个屏幕角都由遮罩覆盖，保存/取消按钮可见，并人工查看截图。解锁、管理等遮罩也不再受全局按钮规则影响。

## 更新提示

参考快照中的 `components/AppSettings.tsx` 和新增 `native/UpdateFlow.java`，采用设置行与更新弹窗分层。更新内容可滚动，操作区固定在底部；支持下载进度、后台查看、取消/重试、校验后的安装入口。Back / Escape 关闭更新弹窗后仍停留在版本设置页。

原始参考来源和 SHA-256 在 `docs/references/zerafun-0.7.4/provenance.json`。仅移植呈现结构，没有替换现有 HTTPS、SHA-256、包名/版本/签名验证。浏览器测试使用模拟未来版本事件覆盖可用、下载中、取消、错误、已验证和无新版状态，不代表从服务器发布了模拟版本。

## 翻页

采用 130ms 整页 0.78 → 1 的淡入，先准备完整位图再切换，不改变谱面几何坐标。MSCZ 全屏、原生自由模式快捷翻页，以及 PDF 自由/全屏翻页使用同一轻量过渡；减少动态效果启用时不创建该动画。

- `tools/verify-page-motion.mjs`：实际动画帧、页面坐标保持、PDF 和减少动态效果。
- 多页点击与导航回归仍通过；截图与本机报告在被 Git 忽略的 `tests/results/`。

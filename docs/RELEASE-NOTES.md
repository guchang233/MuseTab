MuseTab 0.5.1

- 隐藏的谱表不再参与播放；清理已隐藏音符的选择并重建播放事件。
- “我的”直接移植 ZeraFun 0.7.4 的逐级设置菜单结构与样式，换为应用、曲库和文件内容。
- 在“我的 → 应用设置 → 版本与更新”检查、下载和安装正式版本；下载校验 SHA-256、包名、版本和签名。支持每日自动检查。
- 音频合成移到独立 Worker，实时音频回调只复制已准备的 PCM；支持 SIMD，减少排谱和编辑对播放的影响。
- 移动端版面、混音器面板；全屏与自由看谱双指缩放；PDF 三种排版；云端标签保留筛选与滚动位置。
- 下载后的本地乐谱显示“已下载到本地”；播放条移除曲名。
- 看谱点击通过原生命中测试选择音符；忽略轻微手指抖动，拖动先由画布预览再提交视图，减少重绘。
- 编辑的播放按钮旁增加锁定按钮，默认锁定；修改前提示解锁，离开编辑后自动复位。
- 全屏播放显示来自 MuseScore 的播放竖线，默认跟随播放自动翻页，可在播放条中关闭。
- 修复夜间全屏黑纸黑音符；完整页面图片保持已解码缓存，减少回翻时的解码等待。

Android 9+。使用与此前开发包相同的签名，可覆盖安装保留本地数据。安装更新仍需 Android 系统确认。
PDF 识别处于方案阶段，本版不含 OMR，PDF 暂不能直接播放。

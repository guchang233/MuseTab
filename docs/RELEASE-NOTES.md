MuseTab 0.6.2

- 云端及其他标签独立保存格式分类、搜索、滚动位置；打开曲谱再返回和页面重新加载后仍可恢复。手机/平板布局变化时按原曲谱位置恢复。
- 修复系统返回键跳过设置层级的问题：详情 → 设置分组 → 我的；弹窗、筛选和管理面板先关闭当前一层，编辑/看谱再返回上层。
- 从云端详情打开本地曲谱，返回时先回详情，再回原来的云端列表。从设置打开云端，返回时回到来源设置页。
- 保留 0.6.1 多页 MSCZ 点击音符和空白不再瞬移的修复。

Android 9+。使用与此前开发包相同的签名，可覆盖安装保留本地数据。安装更新仍需 Android 系统确认。
PDF 识别处于方案阶段，本版不含 OMR，PDF 暂不能直接播放。

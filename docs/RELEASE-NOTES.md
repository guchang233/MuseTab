MuseTab 0.6.3

- 打开版面、页面/样式设置，以及显示或隐藏声部时改为保留位置的暂停；再次播放从原位置继续。
- 移除误用于所有按钮的圆角覆盖。整屏遮罩完整覆盖四角；圆角仅用于相应控件和面板，恢复设置行、卡片等原有形状。
- 根据 ZeraFun 的 SettingRow 与 UpdateFlow 更新提示结构重做版本页面：独立展示版本、大小、更新内容、下载进度和安装入口。
- MSCZ 和 PDF 翻页加入轻量整页淡入，不移动页面坐标；遵循系统减少动态效果偏好。

Android 9+。使用与此前开发包相同的签名，可覆盖安装保留本地数据。安装更新仍需 Android 系统确认。
PDF 识别处于方案阶段，本版不含 OMR，PDF 暂不能直接播放。

# 0.6.4 声部显示与发声

编辑页原“版面”入口改为“声部”。每行依次为显示复选框、名称、扬声器、上移、下移。乐器行和它下面的谱表行都提供扬声器，触控区域为 44px。

显示与发声互不覆盖。关闭谱表扬声器只停止该谱表的播放；关闭乐器扬声器通过同一组混音器通道静音整件乐器，不改变下属谱表开关。开启乐器后，仍关闭的谱表继续保持静音。混音器的全局静音、独奏规则仍生效。

本次以独立扬声器替代此前“隐藏即静音”的规则，隐藏的谱表也可开启声音；全部隐藏时播放仍可推进。显示变化使用保留位置的暂停，声音开关不执行 stop/rewind。锁定编辑时仍允许操作显示与声音开关。

谱表开关复用 MuseScore 的 `PLAYBACK_VOICE1..4` 属性（每个谱表包含四个记谱声部），原生默认开启并写入 MSCZ。聚合开关关闭四个声部，重新开启则开启这四个声部。原文件已有的逐声部播放属性在导入时保留，播放渲染遵守对应属性。谱表开关支持原生撤销/重做。乐器开关与混音器共用原生 solo/mute 状态，并随项目保存。

原生 PlaybackModel 在谱表播放属性变化和撤销/重做时完整更新事件，避免只重排版而未刷新音频；渲染不再依据谱表可见性删掉音符。播放控制器也不再用“是否可见”作为能否播放的条件。

验证入口：`tools/verify-parts-audio.mjs` 使用合成钢琴双谱表与长笛，检查真实音频频谱、显示和静音独立、乐器与子谱表组合、播放时钟、撤销重做、MSCZ 保存重开，并检查手机/平板横竖屏及明暗主题下的按钮布局。测试文件和截图仅保存在被 Git 忽略的 `tests/results/parts-audio/`。


## 本机验证

- 浏览器全部通过：真实音频中高音频段在单谱表静音后下降约 26 dB；乐器静音后两个钢琴频段均静音，长笛仍播放。显示与声音组合、全部隐藏播放、原生撤销/重做、288 个音符未被删改、MSCZ 重开状态均通过。
- 手机/平板横竖屏 × 明暗主题共 8 种布局通过；扬声器都位于上移/下移左侧，按钮至少 44px，行内容没有横向溢出。
- 用户《芙莉莲》MSCZ 通过显示/隐藏和声音开关的进度回归。开启/关闭单谱表声音涉及原生事件重建，本机在并行浏览器测试下操作耗时约 0.90 / 1.08 秒，播放时钟继续推进，没有回到开头。
- MuMu Android 15 安装 0.6.4 / code 14，通过实际编辑界面按钮验证默认开启、编辑锁定时可用、乐器/谱表组合和显示独立；播放位置从 1.195 秒推进到 2.752 秒，未停止或归零。Android 触控按钮为 48px。此处为模拟器验证，未声称已更新 USB 平板。
- 本地 APK 已核对原生核心与声音桥接资源，未包含私有测试曲谱。CI 正式产物的校验信息由发布任务生成。

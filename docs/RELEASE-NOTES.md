MuseTab 0.7.4-pre.1

- 预发布版，versionCode 31。仅用于测试，正式版客户端不会自动更新到这一版。
- 修复非全屏看谱切换「单页 / 双页 / 连续」时排版错乱的问题。
- 连续排版改用原生画布，不再把整张连续谱当成一页位图纵向拉伸。
- 双页现在会真正并排放下两页；从连续切回单页或双页后画面保持正常。

MuseTab 0.7.3

- 正式版，versionCode 30。应用内「版本与更新」会读到这一版，可覆盖 0.7.2 以及更早的安装包。
- 非全屏看谱点页面左右空白，默认只弹出工具条。要恢复翻页，在「我的 → 应用设置 → 看谱」打开「两侧空白翻页」。
- 点中音符后先出现三点按钮。点开后可以选择播放，或移到上下左右的音符。全屏和非全屏都是这个菜单。
- 非全屏拖动默认预先画好整页，画面外的谱会跟着进来。同一页设置里可以关掉，只移动当前画面。
- Android 9 及以上。安装更新仍需系统确认。同签名覆盖安装，本地曲谱保留。

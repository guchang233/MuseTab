# 当前版本之后的全屏阅读改进

用户要求先完成本轮修复、安装与发布，再处理后补的全屏呈现需求。以下保持在后续队列中，不把它们当作 0.5.0 已完成功能：

1. 全屏自适应单/双页：自动、单页、双页选项；竖屏单页，足够宽高的平板横屏双页，手机优先可读性；旋转保留正在读/播放的页。
2. 翻页不依赖原生视图重定位：独立图片布局，保留相邻页解码结果，预加载和逐页后台准备；在平板记录冷/热翻页延迟，明确上限和内存预算。
3. 全屏使用 MuseScore 原生选中音符的绘制样式，替换现有蓝色框。命中对象已使用原生模型，但位图层的选中外观还需要单独处理。

参照：[forScore 多页模式](https://forscore.co/kb/2-up/)、[MobileSheets 显示模式](https://zubersoft.com/mobilesheets/features/display/)。前者按窗口比例提供并排页；后者也有适合横屏的显示选项。MuseTab 的自动阈值和翻页步长仍需依据真实平板可读性验证，不照搬其他软件全部设置。

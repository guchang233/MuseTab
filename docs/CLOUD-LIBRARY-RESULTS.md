## 曲库

只读访问公开仓库 `guchang233/muse-repo`，自动查默认分支。根目录为 `mid/`、`mscz/`、`pdf/`；
接受大小写和目录内的子文件夹。MIDI 兼容 .mid / .midi。其他目录和不匹配格式的文件忽略。
单文件上限 32 MB；Git LFS 指针会提示改为直接上传文件。

曲库列表缓存到本机。文件下载固定到查询时的提交，校验 Git blob SHA-1 后保存到 IndexedDB。
“保存到本地”只保存，不直接打开。随后在本地谱匣看谱或编辑。
同一云端版本不重复保存；新版本生成新副本，本地编辑和旧版本不会被覆盖或上传。
当前没有 GitHub 登录和双向同步，网络仅发出公开目录及文件的 GET 请求。

## 界面

首页：本地 / 云端入口、继续看谱、搜索和格式筛选。手机使用紧凑列表，平板使用封面网格。
看谱：常态最小顶栏，显式全屏隐藏顶栏和 Android 系统栏，始终保留退出按钮。
Android 返回键先退出全屏，再回谱匣。点音符选择和从选中位置播放保持原操作。
编辑：手机顶栏分两排；录入、时值、变音和声部按两行横向滑动排列。
主操作触摸区域至少 44 px，通常为 48 px。窄屏符号和选中面板从底部展开，
大屏保留侧边面板，画布按工具栏实际高度让出空间。
Android 15 的系统栏边距由容器处理，避免状态栏盖住页面。

## PDF 的范围

PDF 单页按需渲染，支持翻页、页宽适配、放大和全屏。全屏点谱纸可显示工具条。
批注有红 / 蓝画笔、整笔擦除、撤销本页最后一笔；按页在本地保存，重新打开恢复。
PDF 不进行音符识别、音符编辑或播放。`导出原始 PDF` 保留原文件，**不合并批注**；
当前批注尚无跨设备备份或嵌入 PDF 导出功能。MSCZ / MIDI 的原有排谱和编辑路径保留。
PDF.js 使用 legacy 主程序和 worker，CMaps、标准字体均打包在 APK 内，无 CDN 依赖。

## 已确认的结构

| 区域 | 原版实际组件及规则 |
| --- | --- |
| 顶部 | `ScoreReaderChromeBar`：浮动的返回/标题、中央播放、右侧声部/分享/完成区域；不是桌面菜单。总高 62，平板宽度 1180/900 分别切换紧凑控件和播放区域。播放、暂停、停止为分开的按钮。 |
| 主分类 | `ScoreReaderModeToolbar`：平板为音符输入、选择、反复、文本、表情、排版、更多；手机为音符、选择、文本、反复、表情、排版、更多。和弦、歌词、指法是子工具，不能擅自放成顶级分类。 |
| 手机分类栏 | `ScoreReaderCompactModeMetrics`：单元格高 62、图标槽 24、标签 9、单元格选中圆角 10；布局取自源码，不套用统一 44 高按钮。 |
| 平板分类按钮 | 普通/紧凑文本 12/11，内容高 34、选中圆角 9，图标槽 22；两种横向间距和内边距依源码分别实现。 |
| 平板悬浮工具 | `ScoreReaderFloatingToolPalette`：音符内容宽 52，其他内容宽 92，左右内边距 7、上下 9、间距 5、外壳圆角 12；离屏边 16。音符横屏顶部偏移 108，其他情况 148。选择、和弦、歌词、指法、排版、更多不显示这个悬浮栏。 |
| 平板音高区 | `ScoreReaderNoteEntrySurface`：左侧半音调整、中央宽键盘、右侧八度调整。侧区 74×122，键盘高 92，左右间距 18，外边距 24，底部 18。 |
| 手机音高区 | 同组件 compact 分支：左侧撤销/重做，中间 7–8 个自然键的键盘，右侧选择前/后一项；键盘高 86，自然键目标宽 42。不能沿用先前固定两八度键盘。 |
| 手机横屏 | 独立 `compactLandscapeBody`，不是把竖屏界面缩小；控制列与键盘区按源码并排，键盘和侧控采用各自尺寸。 |
| 图标 | 安卓仓库提供的 Material SVG symbolsets，直接复用对应资源；不以现有应用图标近似替换。 |
| 平板判定 | 安卓按设备 idiom（600dp 平板规则），不是 iOS 的最短边 744 规则。不能将 iOS 专用分支当成安卓实现。 |

- 初始选择、单音、和弦、休止、小节与跨小节选区、输入模式、忙碌、错误与不可用状态。

- 顶部播放、练习/节拍设置、混音器、声部、分享/导出与完成。
- 选区旁的上下文工具、面板展开/收起、前后元素导航、键盘滚动/跟随/按键高亮。
- 页面、乐器、谱号、调号、拍号、速度、弱起、自动换行等设置及其应用结果。

还原过程以共享 Swift 文件和安卓条件分支为准。`ScoreReaderEditingDeck` 中存在未被当前主视图使用的旧组件，不能因为文件名匹配就拿来作为最终布局。完成一项需要同时核对控件几何、状态和实际编辑结果，不能用能输入四个音符代替完整还原验收。

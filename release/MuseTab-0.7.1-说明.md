# MuseTab 0.7.1 中文测试包

此包更新编谱界面，依据 Aria 安卓共享源码重建顶部控制、七类工具、悬浮面板和钢琴键盘，并使用原版图标资源。界面文案使用中文；按用户确认，编谱界面不设置额外锁按钮。

选择模式下，琴键修改选中音符的音高；“音符输入”模式下，琴键连续添加音符。拖动键盘只滚动键盘。文本中提供和弦、歌词、指法子工具；混音器和乐器设置连接 MuseScore 原生核心。点击顶部“完成”保存并回到进入编谱前的页面。

验证包括四种手机／平板尺寸、中文面板、编辑保存及撤销、实际音频的分声部静音，以及 MuMu 安卓模拟器实际触控和四次静音／恢复后继续播放。此次未连接用户 USB 平板，不代表该设备的新一轮实机验收。

这是测试包。高级音视频导出及部分上下文细节尚未与 Aria 完全对齐；PDF 自动识别尚未集成进 Android App，不能将本版本视为全部需求已完成。

安装包：`MuseTab-0.7.1.apk`，版本号 0.7.1，版本代码 19。包含本地引擎，打开和编辑曲谱无需联网。
